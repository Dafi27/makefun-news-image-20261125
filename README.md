A program that draws a newspaper front page summing up the world's news of Wednesday 25 November 2026 — the COP31 climate talks collapsing in Antalya, China launching Shenzhou-24 with the first Pakistani astronaut, an Israeli strike killing a Hamas security chief in Gaza, NATO vowing to defend space after reports of a Russian nuclear satellite, Huawei found guilty of stealing trade secrets, and Russia's own figures showing nearly 500,000 dead in the war in Ukraine — as a single 1024x1024 image, using only the Python standard library.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024, under 1 MiB). Run it twice and the two files are byte-identical.
